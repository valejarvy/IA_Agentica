# disenar_programa

## Objetivo
Convertir los requisitos en una estructura de programa que pueda implementar el ProgramadorAgente.

## Entrada
- Requisitos funcionales obtenidos de `analizar_requisitos`.

## Proceso
1. Relacionar cada proceso con una funcion o metodo.
2. Proponer una clase si se necesita guardar datos relacionados.
3. Definir las responsabilidades de cada parte.
4. Indicar los archivos o modulos minimos.

## Salida
Un diseno con la clase, funciones, datos y archivos necesarios.

## Como convertir requisitos en estructura
- Las entradas se convierten en parametros o datos solicitados al usuario.
- Los procesos se convierten en funciones o metodos.
- Las salidas se convierten en valores retornados o mensajes.
- Las reglas se convierten en validaciones.

## Funciones necesarias
Cada funcion debe realizar una accion concreta: registrar datos, calcular un resultado, consultar datos o mostrar resultados.

## Clases necesarias si aplican
Usar una clase cuando el programa administre varios datos del mismo tipo. Para un registro academico puede usarse una clase `RegistroSimple`.

## Archivos o modulos necesarios
- Un archivo Python principal para el programa generado.
- No agregar modulos si el problema puede resolverse en un solo archivo.
