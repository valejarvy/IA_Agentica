# generar_codigo

## Objetivo
Convertir un diseno aprobado en codigo fuente Python funcional.

## Entrada
- Requisitos funcionales.
- Diseno del programa.
- Correcciones solicitadas por pruebas, si existen.

## Proceso
1. Crear las clases y funciones indicadas en el diseno.
2. Implementar las validaciones.
3. Agregar una interfaz sencilla de linea de comandos cuando sea necesaria.
4. Entregar el codigo en un archivo `.py`.

## Salida
Codigo fuente ejecutable y entendible para un estudiante universitario.

## Reglas para generar codigo
- Usar nombres en espanol claros.
- Evitar dependencias externas si no son necesarias.
- No mezclar la logica principal con las pruebas.
- Mostrar mensajes utiles al usuario.

## Reglas de calidad
- Mantener funciones pequenas.
- Validar datos vacios y valores fuera de rango.
- Incluir comentarios solo cuando ayuden a comprender una decision.
- El codigo debe poder ejecutarse con Python 3.

## Forma de entregar el codigo
Entregar el contenido completo del archivo fuente e indicar su ruta. Si hay un error reportado, entregar una version corregida del mismo archivo.
